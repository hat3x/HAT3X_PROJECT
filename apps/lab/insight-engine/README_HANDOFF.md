# HAT3X Demo Automator — Handoff desde Lovable

## 🧠 Contexto

Este proyecto es la versión inicial (v1) de una aplicación interna de HAT3X creada en Lovable.

HAT3X es una consultora de automatización e inteligencia artificial para negocios.

Esta aplicación tiene como objetivo convertirse en una herramienta interna de ventas y preventa que permita analizar negocios automáticamente y generar demos personalizadas para cerrar clientes más rápido.

---

## 🎯 Objetivo del producto

Convertir una URL de negocio en:

- Análisis estructurado del negocio
- Identificación de oportunidades
- Recomendación de soluciones con IA
- Generación de demo personalizada
- Generación de email de contacto
- Preparación del lead para seguimiento comercial

---

## ⚙️ Flujo actual (v1)

1. Introducción de URL
2. Simulación de análisis
3. Sugerencia de demo
4. Visualización de demo
5. Generación de email

---

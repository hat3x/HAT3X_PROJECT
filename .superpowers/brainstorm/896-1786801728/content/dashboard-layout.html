D · Mosaico adaptativo

Cada proyecto es un mosaico y el tamaño lo decide la urgencia: lo que está roto se agranda solo, lo sano se encoge. Pensado para dejarlo en una pantalla siempre encendida.

Pero: la posición de las cosas cambia sola, y eso cansa cuando lo usas para trabajar y no solo para mirar.
